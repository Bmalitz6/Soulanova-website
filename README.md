Includes four new sections: How It Works, Foods to Enjoy, Meal Ideas, Healthy Habits.

Reference: https://my.clevelandclinic.org/health/articles/16037-mediterranean-diet

## Deploy

Use your EXISTING GitHub `soulanova-website` repository and Vercel project. Unzip this package, replace the existing root `index.html`, `styles.css`, `script.js`, `README.md` and `assets/soulanova-logo.png` with the corresponding files, and commit to the production branch (usually main). Vercel should deploy automatically. If GitHub browser upload cannot overwrite existing files, edit/delete the old files first or use GitHub Desktop. Do not create another Vercel project.

The site is still a coming-soon informational website. It does not offer active subscriptions, a meal planner, or personalized medical advice. Complete trademark and legal review before a full commercial launch.
